# ICD 341: Advanced Statistical Computing

This repository contains all my laboratory work and the final capstone project for ICD 341 at Mulungushi University.

## Repository Structure

### Core Laboratories
- **Lab 1:** Python Environments, JupyterLab, VS Code and Git
- **Lab 2:** NumPy Fundamentals and Array Operations
- **Lab 3:** NumPy Vectorization and Broadcasting
- **Lab 4:** Profiling and Benchmarking Python Code
- **Lab 5:** Linear Algebra and Regression
- **Lab 6:** Matrix Decompositions and Sparse Matrices
- **Lab 7:** Optimization and Maximum Likelihood Estimation (MLE)
- **Lab 8:** Monte Carlo Simulations
- **Lab 9:** Bootstrap and Resampling
- **Lab 10:** Bayesian MCMC
- **Lab 11:** Advanced Simulation
- **Lab 12:** Testing, Estimators, and Packaging
- **Lab 13:** Performance and Scalability
- **Lab 14:** Expectation-Maximization (EM) Algorithm
- **Lab 15:** Neural Networks with PyTorch
- **Lab 16:** Notebook Hygiene and Reproducibility
- **Lab 17:** Streamlit Dashboards

### Capstone Project
- **`ICD341_Capstone`**: A fully packaged, deployable version of the Streamlit Dashboard project, including data, source scripts, outputs, and documentation.
