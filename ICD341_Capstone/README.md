# ICD 341 Capstone Project

## Project Overview
This capstone project analyzes agricultural data and visualizes it using an interactive dashboard.

## Project Structure
- `dashboard/`: Contains the Streamlit web application (`app.py`) and screenshots.
- `data/`: Contains raw datasets.
- `notebooks/`: Jupyter Notebooks for data exploration and analysis.
- `outputs/`: Saved graphs and reports.
- `src/`: Python scripts for data processing.
- `requirements.txt`: List of required Python packages.

## How to Run
1. Install the requirements: `pip install -r requirements.txt`
2. Run the app: `streamlit run dashboard/app.py`
