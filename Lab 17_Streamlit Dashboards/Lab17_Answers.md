# LAB 17: Questions & Answers

**1. What is Streamlit?**
*Answer:* Streamlit is an open-source Python library used to create interactive web applications and dashboards for data science and machine learning. It turns Python scripts into shareable web apps with just a few lines of code.

**2. Explain the purpose of `st.sidebar`.**
*Answer:* `st.sidebar` creates a panel on the left side of the dashboard. It is used to hold interactive controls like sliders, dropdowns, and text inputs, allowing users to filter data or change parameters without cluttering the main view.

**3. What does `st.columns()` do?**
*Answer:* `st.columns()` divides the main dashboard area into multiple vertical columns. This helps organize the layout, such as displaying a data summary on the left and a chart on the right.

**4. Why is Streamlit useful for statistical computing?**
*Answer:* Streamlit bridges the gap between statistical analysis and stakeholders. Instead of sharing a static report, a data scientist can create a tool where users interact directly with the models and data in real-time.

**5. How do you run a Streamlit app from the terminal?**
*Answer:* You run it using the command `streamlit run your_script.py`. This starts a local web server and opens the app in your default web browser.
